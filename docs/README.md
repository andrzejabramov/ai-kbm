# 🤖 AI-Агент Отдела продаж ООО «КБМ»

Интеллектуальный ассистент для менеджеров по продажам буровых наконечников. Автоматизирует обработку заявок клиентов, запрашивает себестоимость у технолога и рассчитывает маржинальность.

**Приложение подготовлено с помощью нейромодели Qwen3.7-Plus**

## 🎯 Возможности

- ✅ Парсинг заявок клиентов (клиент, товар, количество, срок)
- ✅ Формирование черновика «Заказа покупателя»
- ✅ Запрос себестоимости у технолога (имитация)
- ✅ Расчёт маржинальности и рекомендации
- ✅ Экспорт истории чата в CSV
- ✅ Адаптивный веб-интерфейс
- ✅ Docker-контейнеризация для продакшена

## 🛠 Технологии

- **Backend:** Flask + Gunicorn
- **AI:** Qwen через OpenRouter API (бесплатные модели с fallback)
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Deployment:** Docker + Docker Compose
- **Infrastructure:** Proxmox VM
