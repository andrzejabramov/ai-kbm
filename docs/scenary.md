## 🎥 Видео 3: "Загрузка базы знаний в ChromaDB: RAG для AI-агентов"

### Структура видео (8-10 минут)

#### 0:30 - 2:00 | Что такое RAG

**Кадр:** Схема RAG  
**Текст:**

> "RAG — это Retrieval-Augmented Generation. Когда пользователь задаёт вопрос, AI не отвечает из головы, а сначала ищет релевантные фрагменты в базе знаний, а потом генерирует ответ на их основе. Это повышает точность и снижает галлюцинации."

#### 2:00 - 4:00 | Загрузка данных в ChromaDB

**Кадр:** Код загрузки  
**Текст:**

> "Мы загрузили все .md файлы (регламенты, спецификации, инструкции) в ChromaDB. Код простой:
>
> ```python
> import chromadb
> from langchain.text_splitter import RecursiveCharacterTextSplitter
>
> client = chromadb.Client()
> collection = client.create_collection("kbm_knowledge")
>
> # Загружаем .md файлы
> for file in glob.glob("docs/*.md"):
>     with open(file) as f:
>         text = f.read()
>
>     # Разбиваем на чанки
>     splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
>     chunks = splitter.split_text(text)
>
>     # Добавляем в коллекцию
>     collection.add(
>         documents=chunks,
>         metadatas=[{"source": file}] * len(chunks),
>         ids=[f"{file}_{i}" for i in range(len(chunks))]
>     )
> ```
>
> Теперь AI может искать по всей базе знаний."

#### 4:00 - 6:00 | Поиск и генерация

**Кадр:** Код поиска  
**Текст:**

> "Когда мастер задаёт вопрос, мы ищем релевантные фрагменты:
>
> ```python
> def answer_question(question):
>     # Ищем релевантные фрагменты
>     results = collection.query(
>         query_texts=[question],
>         n_results=3
>     )
>
>     # Формируем промпт с контекстом
>     context = "\n".join(results["documents"][0])
>     prompt = f"""
>     Контекст:
>     {context}
>
>     Вопрос: {question}
>
>     Ответ:
>     """
>
>     # Генерируем ответ
>     response = llm.generate(prompt)
>     return response
> ```
>
> AI читает контекст и генерирует точный ответ."

#### 6:00 - 8:00 | Примеры

**Кадр:** Демонстрация  
**Текст:**

> "Пример 1: Мастер спрашивает: 'Как сдать продукцию в ОТК?'. AI ищет в базе знаний, находит фрагмент из `07_otk_controller.md` и отвечает: 'Откройте отчёт производства за смену, укажите склад-получатель "Склад ОТК", проведите документ'."
>
> "Пример 2: Снабженец спрашивает: 'Какие материалы нужны для НБ-120?'. AI ищет в спецификациях, находит фрагмент из `06_production_workshop.md` и отвечает: 'Для НБ-120 нужно: Сталь 40Х — 4 кг, Электроды УОНИ — 0.5 кг'."

#### 8:00 - 9:30 | Ошибки и решения

> 3. **Прямое подключение к БД** — быстро, но небезопасно.
>
> Мы выбрали HTTP-сервисы, потому что это стандартно, безопасно и легко отлаживать."

#### 2:00 - 4:00 | Создание HTTP-сервиса в 1С

**Кадр:** Код 1С (встроенный язык)  
**Текст:**

> "В 1С мы создали HTTP-сервис:
>
> ```1c
> // Модуль HTTP-сервиса
> Функция CreateProductionReport(Запрос) Экспорт
>
>     // Парсим JSON
>     Данные = JSON.Прочитать(Запрос.Body);
>
>     // Создаём документ
>     Док = Документы.ОтчетПроизводстваЗаСмену.СоздатьДокумент();
>     Док.Дата = ТекущаяДата();
>     Док.Заказ = Данные.Заказ;
>     Док.Количество = Данные.Количество;
>
>     // Заполняем табличную часть
>     Для Каждого Рабочий Из Данные.Рабочие Цикл
>         Строка = Док.Рабочие.Добавить();
>         Строка.Рабочий = Рабочий;
>     КонецЦикла;
>
>     // Проводим документ
>     Док.Провести();
>
>     // Возвращаем результат
>     Результат = JSON.Записать({Статус: "OK", ID: Док.УникальныйИдентификатор()});
>     Возврат Результат;
>
> КонецФункции
> ```
>
> Этот сервис принимает JSON, создаёт документ в 1С, возвращает ID."

#### 4:00 - 6:00 | Вызов из Python

**Кадр:** Код Python  
**Текст:**

> "В Python мы вызываем этот сервис:
>
> ```python
> import requests
>
> def create_production_report(order, quantity, workers):
>     url = "http://1c-server/hs/api/create_production_report"
>     data = {
>         "order": order,
>         "quantity": quantity,
>         "workers": workers
>     }
>
>     response = requests.post(
>         url,
>         json=data,
>         auth=("user", "password"),
>         timeout=10
>     )
>
>     if response.status_code == 200:
>         return response.json()
>     else:
>         raise Exception(f"Ошибка 1С: {response.text}")
